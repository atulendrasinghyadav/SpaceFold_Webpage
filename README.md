# SpaceFold Webpage

SpaceFold is an interactive physics simulation app landing page built with React and Vite. It serves as the promotional and informational site for the SpaceFold Augmented Reality (AR) app, which helps users visualize curved spacetime, time dilation, and the perspective of relativistic observers using immersive AR experiences.

## 🚀 Concept

Not Equations. **Experiences.**

For over a century, the Theory of Relativity has been locked behind complex math. SpaceFold changes that. By leveraging the power of Augmented Reality and Apple's Foundation Models, we've transformed abstract concepts into tangible visual and haptic experiences. Step into the fabric of spacetime right from your living room.

## ✨ Core Features

Three distinct modules designed from the ground up to make advanced physics intuitive and experiential:

- **🌌 Spacetime Fabric**: Toss virtual masses like bowling balls onto the AR spacetime grid and watch how gravity naturally pulls smaller objects into orbit.
- **⏱️ Time Dilation**: Move physical devices at varying speeds to observe real-time tick-rate changes of virtual clocks, directly proving time is relative.
- **👁️ Observer Perspective**: Switch seamlessly between multiple AR reference frames to see how light and motion appear to different observers at the same moment.

## 🛠️ How It Works

1. **Scan Surface**: Scan your immediate surroundings to map surfaces and seamlessly anchor the Augmented Reality fabric.
2. **Interact with Models**: Once the grid is established, spawn physical masses and deform spacetime using intuitive hand gestures.
3. **Ask the AI**: Have any doubts during an experiment? Ask the integrated foundation model for instant, deep physics clarification.

## 💻 Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Styling**: Vanilla CSS with modern dynamic designs (Glassmorphism, glow effects)

## 📥 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

Ensure you have Node.js and npm installed on your machine.
- Node.js (v18+ recommended)
- npm or yarn

### Installation & Running Locally

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   ```

2. **Navigate to the project directory**
   ```bash
   cd SpaceFold_Webpage
   ```

3. **Install the dependencies**
   ```bash
   npm install
   ```

4. **Start the development server**
   ```bash
   npm run dev
   ```
   This will start the local server, typically on `http://localhost:5173`.

### Build for Production

To build the project for production, run:

```bash
npm run build
```
The compiled assets will be placed in the `dist` folder. You can preview the production build using:

```bash
npm run preview
```
